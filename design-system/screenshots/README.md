# AgentFlow Design System — Screenshots & Render Evidence

This directory houses visual render references and testbed recordings for the Open Design v2 handoff:

1. `hero-canvas.png`: Full DAG orchestration canvas with Trigger, Action, Logic, and AI Agent nodes.
2. `components-fixture.png`: Rendering of `components.html` proving all button variants, semantic badges, 3 form states, tabs, and 5 surface card states.
3. `modal-credentials.png`: Credential vault modal with provider search, masked inputs, and AES-256 test indicators.
4. `template-marketplace.png`: Responsive template grid with categorizations and connector badges.
5. `bot-telemetry-drawer.png`: Sliding drawer with live task logs, MCP invocations, and browser session previews.

All components are live-rendered and testable via the standalone fixtures under `design-system/preview/` and `design-system/components.html`.
