## 6. Technical Architecture & Security Isolation

- **Section Kicker**: `SECURITY-FIRST ARCHITECTURE`
- **Section Headline (H2)**:
  > **Zero-trust containment. Ephemeral by design.**
- **Section Subtitle**:
  > Enterprise security teams approve AgentFlow Bot because every action runs in an isolated container that terminates after execution.

### Architectural Pillars:

- **Ephemeral gVisor Sandboxes**: Each browser session runs inside an isolated container with its own private Xvfb display, virtual audio loopback, and restricted filesystem access.
- **Credential Masking & Ephemeral Profiles**: Credentials are injected into memory at the socket layer. Session cookies and storage keys are encrypted and destroyed upon task teardown.
- **Audit Logs & Visual Flight Recorder**: Every mouse click, keystroke, network call, and DOM snapshot is recorded into immutable, timestamped execution traces with OpenTelemetry.
- **Strict Network Egress Controls**: Custom DNS filters and IP allowlisting prevent the sandbox from communicating with unauthorized endpoints or private intranets.

## 9. Frequently Asked Questions (FAQ)

1. **How does AgentFlow Bot handle Cloudflare and anti-bot protections?**
   > AgentFlow Bot uses authentic Chromium fingerprints, realistic mouse trajectory physics, dynamic viewport jitter, and integration with enterprise residential proxy pools. Unlike standard headless scrapers, it renders the complete graphical stack inside Xvfb, passing human verification benchmarks seamlessly.

2. **Can I interact with the browser while the AI is operating?**
   > Yes. With 1-Click Human Takeover, you can take control of the mouse and keyboard instantly through the WebRTC canvas. Complete a captcha or approve a transaction, and hand control back to the AI with a single click.

3. **Are my credentials and passwords exposed to the AI model?**
   > No. Credentials are stored in the encrypted AgentFlow Vault and injected directly into target web inputs via secure browser context handlers. The LLM only receives confirmation tokens and semantic status, never raw plaintext passwords.

4. **Can I trigger browser bot workflows from APIs or webhooks?**
   > Absolutely. AgentFlow Bot is fully exposed as an MCP Server and REST/Webhook endpoint. You can trigger browser actions from an AgentFlow visual canvas, a GitHub Action, a Slack bot, or your own internal backend.

5. **What happens if a web page layout changes?**
   > Because AgentFlow Bot is powered by multimodal vision reasoning, it identifies elements by visual meaning and context rather than fragile static CSS selectors. If a button changes color or moves from the sidebar to a dropdown, the agent perceives the new layout and adapts automatically.
